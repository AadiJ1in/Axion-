# Interface sprint release notes (draft)

This branch is a presentation and interaction sprint. It intentionally leaves authentication, authorization, therapist verification, prescriptions, assignment identifiers, roadmap authority, session context, rep validation, clinical targets, and Supabase persistence unchanged.

Implemented presentation changes include:

- rehabilitation-first public homepage and clearer public navigation
- explicit patient/therapist demo entry points
- four-item patient primary navigation
- contextual Report a concern action
- four-column safe-area-aware mobile patient navigation
- focused Today and Journey states
- synthetic demo labeling for homepage example metrics
- simplified active Movement Lab controls and hidden patient-facing diagnostics
- standard-mode professional rest language
- four-item therapist primary navigation with review cues centered in Overview
- Session Review / Session score presentation terminology where legacy labels were ambiguous
- compact demo-environment disclosure with full boundary retained in About this demo
- responsive and keyboard-focus regression tests
- documented CSS consolidation path without deleting live legacy selectors
